# Java Programs (100 Basic Programs)

A collection of 100 beginner-friendly Java programs covering numbers, patterns, arrays, strings, OOP and other core concepts.

## How to run
```
cd 02-numbers
javac PrimeNumber.java
java PrimeNumber
```

Compile and run one file at a time. Programs that read input will ask you to type values in the terminal.
